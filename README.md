# HMH — سامانه رزرواسیون آمفی‌تئاتر مدارس امام حسین (ع) یزد
## Imam Hossein Schools Central Amphitheater Reservation Management System

**موسسه خیریه فرهنگی آموزشی حضرت امام حسین (ع) یزد**

این سامانه یک بستر یکپارچه و امن آنلاین برای مدیریت، زمان‌بندی و رزرو سانس‌های سالن آمفی‌تئاتر مرکزی برای مدارس شش‌گانه موسسه است.

---

### بخش‌های سامانه (فاز ۱ - نسخه رایانه و وب):
1. **اپلیکیشن نیتیو ویندوز (Windows Desktop Application):**
   - توسعه یافته با Flutter دسکتاپ برای سیستم‌عامل‌های ویندوز ۱۰ و ۱۱ (x64)
   - تقویم هفتگی شمسی کامل (شنبه تا جمعه) با ۵ سانس زمانی روزانه
   - تفکیک رنگ پاستلی وضعیت‌ها (آزاد: سبز، رزرو شده: آبی، تعطیل رسمی: قرمز، مسدود: خاکستری)
   - فرم پنجره ثبت رزرو سریع با پر شدن خودکار مشخصات مدرسه و کاربر
   - اعمال هوشمند حریم خصوصی شماره تماس متقاضیان
   - سوابق رزروهای کاربر و امکان لغو فوری توسط خود کاربر یا مدیر ارشد

2. **پنل وب مدیریت کل (Super Administrator Web Panel):**
   - توسعه یافته با React 18، TypeScript، Vite و Tailwind CSS
   - ۱۰ بخش جامع مدیریتی: داشبورد آماری، کاربران، مدارس، رزروها، سانس‌ها، تعطیلات، محدودیت‌ها، گزارش‌ها و اکسل، لاگ‌های امنیتی (Audit Log)، و تنظیمات ارتباط با سرور
   - بخش اختصاصی «تنظیمات اتصال به سرور» مطابق با طرح تایید شده کارفرما
   - قابلیت آزمایش آنلاین ارتباط با سرور، پایگاه‌داده، RESTful API و گواهی SSL

3. **هسته مرکزی بک‌اند (Central FastAPI Backend):**
   - معماری ماژولار و ناهمگام با Python 3.13 و FastAPI
   - سیستم جلوگیری قطعی از تداخل زمانی و رزرو همزمان (Double-Booking Prevention) بر پایه تراکنش‌های ACID و قید یکتایی دیتابیس
   - احراز هویت امن بر پایه توکن‌های JWT و هش رمزنگاری Argon2id
   - همگام‌سازی بلادرنگ تمامی کلاینت‌های متصل از طریق وب‌سوکت (WebSocket)

4. **پایگاه داده متمرکز (MySQL 9.7 LTS):**
   - استفاده از موتور InnoDB و کاراکترست `utf8mb4`
   - ذخیره تاریخ‌ها به صورت استاندارد میلادی در دیتابیس و تبدیل شمسی در لایه نمایش
   - سیستم پشتیبان‌گیری خودکار روزانه همراه با هش SHA-256 و نگهداری دوره‌ای

5. **زیرساخت استقرار لینوکس (Ubuntu 24.04 LTS):**
   - بسته‌بندی کانتینری کامل با Docker Compose
   - وب‌سرور معکوس Nginx با انتقال خودکار به HTTPS و گواهی Let's Encrypt
   - ایزوله‌سازی کامل پورت دیتابیس در شبکه خصوصی
