# راهنمای جامع بازیابی اطلاعات و بازگشت از بحران
## سامانه متمرکز رزرواسیون آمفی‌تئاتر مدارس امام حسین (ع)

**سیستم‌عامل سرور:** Ubuntu 24.04 LTS  
**پایگاه داده:** MySQL 9.7 LTS  

---

### ۱. تدابیر پیش از بازیابی اطلاعات
پیش از شروع فرایند بازگردانی:
۱. اطمینان حاصل فرمایید که هیچ کاربر فعالی در حال ثبت رزرو نباشد (ترجیحاً کانتینر بک‌اند را متوقف سازید):
   ```bash
   docker stop hmh_backend
   ```
۲. قبل از رونویسی دیتابیس فعلی، یک بکاپ اضطراری از وضعیت کنونی بگیرید.
۳. چکسام فایل پشتیبان انتخابی را اعتبارسنجی نمایید تا از عدم خرابی داده‌ها اطمینان یابید.

---

### ۲. اعتبارسنجی چکسام SHA-256
برای بررسی سلامت نسخه پشتیبان:
```bash
cd /opt/hmh/backups
sha256sum -c hmh_backup_YYYYMMDD_HHMMSS.sql.gz.sha256
```
در صورت دریافت خروجی `OK`، فایل سالم و آماده بارگذاری در دیتابیس است.

---

### ۳. فرایند بازیابی با اسکریپت خودکار (`restore.sh`)
اسکریپت `restore.sh` در مسیر `deployment/scripts/restore.sh` طراحی شده است:
```bash
cd /opt/hmh/deployment/scripts
chmod +x restore.sh
sudo ./restore.sh /opt/hmh/backups/hmh_backup_YYYYMMDD_HHMMSS.sql.gz
```
این اسکریپت مراحل زیر را اجرا می‌کند:
- بررسی وجود و درستی نام کاربری و رمز دیتابیس در فایل تنظیمات `.env`
- تست اتصال و بازگشایی فایل فشرده `.gz`
- اعمال اسکریپت SQL در پایگاه‌داده `hmh_database` درون کانتینر MySQL
- بررسی موفقیت تراکنش‌ها و راه‌اندازی مجدد وب‌سرویس بک‌اند

---

### ۴. بازیابی دستی از طریق Docker Exec
در صورت نیاز به بازگردانی مستقیم از طریق کنسول لینوکس:
```bash
zcat /opt/hmh/backups/hmh_backup_XXXXXX.sql.gz | docker exec -i hmh_mysql mysql -u hmh_user -p"SECURE_PASSWORD" hmh_database
```
پس از اتمام:
```bash
docker restart hmh_backend
```
سپس پنل وب یا نرم‌افزار ویندوز را باز کرده و صحت بارگذاری رزروها و کاربران را تایید فرمایید.
