# راهنمای دامنه، DNS و گواهی امنیتی SSL Let's Encrypt
## سامانه رزرواسیون آمفی‌تئاتر مدارس امام حسین (ع)

### ۱. تنظیم رکوردهای DNS دامنه
در پنل مدیریت دامنه یا کلودفلر/ابرآروان، رکوردهای زیر را به IP سرور لینوکس اختصاصی متصل نمایید:

| نوع رکورد | نام میزبان | مقدار (مقصد) | وضعیت Proxy |
|---|---|---|---|
| A | `@` (یا salehvip-clud.ir) | `<VPS_PUBLIC_IP>` | DNS Only |
| A | `reserve` | `<VPS_PUBLIC_IP>` | DNS Only |

### ۲. بررسی اتصال DNS قبل از صدور SSL
با اجرای دستور زیر اطمینان حاصل کنید که دامنه به IP سرور شما متصل شده است:
```bash
dig +short reserve.salehvip-clud.ir
# خروجی باید IP سرور شما را نشان دهد
```

### ۳. صدور خودکار گواهی SSL Let's Encrypt
```bash
./app/Server-Deployment/scripts/setup_ssl.sh
```

### ۴. تمدید خودکار (Auto Renewal)
گواهی‌های Let's Encrypt نود روزه بوده و کانتینر Nginx با وب‌روت `/var/www/certbot` به‌صورت خودکار امکان تمدید بدون قطعی سرویس را فراهم می‌سازد.
