# راهنمای جامع نصب و استقرار سامانه HMH
## سامانه رزرواسیون مرکزی آمفی‌تئاتر مدارس امام حسین (ع) یزد

### پیش‌نیازهای سخت‌افزاری و نرم‌افزاری
- **سرور میزبان:** لینوکس اوبونتو 24.04 LTS (حداقل ۲ هسته پردازنده، ۴ گیگابایت رم، ۴۰ گیگابایت حافظه SSD)
- **محیط کانتینری:** Docker نسخه 26+ و Docker Compose نسخه v2.20+
- **کلاینت‌های مدارس:** ویندوز 10 یا 11 (نسخه 64 بیتی) با حداقل ۴ گیگابایت رم

---

### مراحل سریع راه‌اندازی سرور مرکزی:
```bash
# ۱. دریافت کدها یا انتقال پکیج سرور
cd /opt/hmh

# ۲. ساخت فایل متغیرهای محیطی با رمزهای تصادفی قوی
cp .env.example .env
nano .env

# ۳. اجرای اسکریپت استقرار خودکار
chmod +x source/deployment/scripts/deploy.sh
./source/deployment/scripts/deploy.sh
```
